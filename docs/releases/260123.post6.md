# UTP v260123.post6

Transactional Home/Warp writes preserve disk and memory on failure; stale forms and changed permissions cannot mutate or teleport. Existing schemas and destination metadata are preserved. Cancelled teleports do not report success.

Validation: automated regression tests and wheel validation. No real BDS runtime or power-loss/crash-kill validation was performed for this refactor. Existing configuration and data should be backed up before upgrading.

Installation: stop the server, activate its current Python environment, then run `uv pip install --upgrade ./endstone_utp-260123.post6-py3-none-any.whl`. Restart the server. Do not copy this wheel into plugins; install it into the environment used by Endstone.
